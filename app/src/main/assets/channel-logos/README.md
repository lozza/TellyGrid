# Channel identity artwork

These resized PNGs are generated by `scripts/update-channel-logos.ps1` from the
source URLs recorded in `ChannelLogoCatalog.kt`. They are included locally so the
TV interface does not depend on rate-limited or geo-blocked image hosts.

Channel names and logos are trademarks of their respective owners. Inclusion here
identifies the destination channel; it does not imply endorsement, affiliation, or
ownership by TellyGrid. Review redistribution rights before a public store release.
